WhatsBot CRM Cloud V7

Esta edición conserva la aplicación V6 y agrega únicamente archivos de despliegue cloud.

Requisitos del hosting:
- Node.js 22 o contenedor Docker.
- Proceso web siempre activo.
- Puerto entregado por la variable PORT.
- Volumen persistente montado en /data.
- HTTPS público.

Variables recomendadas:
NO_OPEN=1
WHATSBOT_HOST=0.0.0.0
WHATSBOT_DATA_DIR=/data

Railway:
- Crear un servicio desde este proyecto.
- Agregar un Volume y montarlo en /data.
- Generar dominio público HTTPS.

Render:
- El archivo render.yaml define un Web Service Docker con disco persistente /data.

Migración desde V6:
- En V6: Datos y respaldos > Exportar respaldo completo.
- En V7 Cloud: importar ese respaldo completo.
- Verificar WhatsApp QR/API y usuarios.

Importante:
- No usar hosting serverless para el modo WhatsApp QR/Baileys, porque requiere un proceso Node persistente.
- La carpeta /data debe ser persistente para conservar base, multimedia y sesión de WhatsApp.
